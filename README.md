# Modelo COMBINAR para Cultura Organizacional en Manufactura

Metodología de desarrollo humano aplicada a entornos industriales que integra Propósito, Procesos y Personas mediante la Sintonía y el Micelio.

## Características principales

- **3 Rutas de aplicación**: Asertividad (Frecuencia), Trabajo en Equipo (Micelio) y Liderazgo (Raíz)
- **Diagnóstico inicial**: Radiografía de Combinación (5 dimensiones)
- **Plan de implementación**: 90 días (Sintonizar, Integrar, Encarnar)
- **Enfoque**: Manufactura y entornos multilatinos

## Tecnologías

- HTML5
- CSS3 (Responsive)
- Sin dependencias externas
